## 三、省略风格规范（混合风格，已与需求方确认）

1. **方法体/数据体折叠**：用 `...`（Python Ellipsis 字面量，语法合法）或单行注释替代：

   ```python
   def __init__(self):
       # 内置正文直接写在代码里（skill-creator / code-review 两段）；全文见代码文件
       self._bodies = {...}
   ```

2. **文件头样板折叠**：块首用一行注释指路，沿用项目现有惯例：

   ```python
   # ch02/code/main.py（本章可运行入口）
   # ... docstring 与跨章导入路径处理（第 1-25 行）从略，见代码文件 ...
   import os, sys  # 若后文演示段仍引用则保留必要 import 行

   def main():
       ...
   ```

3. **折叠处必须说明「省略了什么、去哪看」**：注释里给出代码文件的行号范围或"见代码文件"，读者可随时回源核对；
4. **不折叠的部分保持与实际代码逐字一致**（延续文档同步原则）；
5. **类/函数骨架完整性**：折叠后类体不得为空（至少 `...` 占位），缩进层级不变，装饰器与其定义不分离。

## 四、验收标准（已与需求方确认：语法校验）

1. **语法合法**：每个修改过的代码块提取后（按块首缩进 dedent）能通过 `ast.parse`；
2. **zh/en 同步**：同一块的折叠在两版文档中一致（en 版注释用英文）;
3. **指路有效**：折叠注释中引用的行号范围与 `code/` 实际文件核对无误；
4. **运行输出不变**：本任务只改 md，不触碰 code/，各章 main.py 行为不受影响（跑一遍全量回归确认）。
